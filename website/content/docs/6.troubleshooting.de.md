Die meisten Punkte unten stammen aus echten Tester-Berichten. Fehlt deiner, spring zu [Ein Problem melden](#bugs-und-feature-wuensche) und schick ihn ein.

## Installation und Öffnen

**macOS kann die App nicht überprüfen.** Stelle sicher, dass du die DMG von der offiziellen [Releases-Seite](https://github.com/gwonmac/gwonmac/releases/latest) geladen hast. Releases sind signiert und notarisiert, Gatekeeper prüft sie ohne jeden Workaround. Deaktiviere niemals Gatekeeper und ändere keine globalen Sicherheitseinstellungen. Ein Build, der das verlangt, ist kein offizielles Release.

**Der Download hängt oder das Spiel wird nicht fertig vorbereitet.** Nutze den Retry im Launcher oder beende und öffne die App neu; Downloads setzen dort fort, wo sie aufgehört haben. Schlägt es weiter fehl, blockiert dein Netzwerk möglicherweise das ArenaNet-CDN.

**Nach einem Update funktioniert etwas nicht mehr.** Aktualisiere zuerst auf das neueste Release. Besteht das Problem weiter, melde es.

## Probleme im Spiel

**Importierte Templates tauchen im Spiel nicht auf.** Guild Wars liest seine Template-Liste einmal pro Sitzung — öffne das Template-Fenster und wähle **Refresh List**, oder starte das Spiel neu. Siehe [Templates: Import & Export]($docs.templates).

**Ein Template-Ordner ist da, aber leer.** Guild Wars liest nie, was in einem Unterordner steht, den es nicht selbst geschrieben hat — alles darin bleibt im Spiel unsichtbar. Template-Dateien, die du aus einem Windows-Unterordner importierst, behalten den Ordnernamen deshalb im Template-Namen — siehe [Templates: Import & Export]($docs.templates).

**Adrenalin-Skill-Symbole flackern beim Aufladen.** Bekanntes Problem in ArenaNets WebAssembly-Client; die Mobilversion zeigt dasselbe Verhalten. Das kann GWonMac nicht beheben.

**Audio knistert oder stottert.** Stelle sicher, dass der vollständige Spiel-Download abgeschlossen ist, und wähle in den Spieleinstellungen die höchste Audioqualität.

**Kein Antialiasing außer „None“.** Das ist der aktuelle WebAssembly-Client, wie auf Mobilgeräten. Eine höhere Render-Skalierung (**Guild Wars → Einstellungen → Anzeige**) kommt dem am nächsten.

## Features und Add-ons

**GWToolbox++ funktioniert nicht.** Es klinkt sich in den Windows-Client ein, den GWonMac nicht ausführt. Nutze stattdessen die Features von GWonMac: Schalte dazu auf der Seite **Features** im Launcher :setting[Play the plain game]{to="features/gwonmacTools"} aus. Einige Features, etwa Target Distance und Maps, funktionieren nur in PvE und schalten sich in PvP und in unbekannten Gebieten ab. Gildenhallen zählen als PvE.

## Bugs und Feature-Wünsche

1. Wähle **Help → Report a Bug…**, um das [GitHub-Bug-Formular](https://github.com/gwonmac/gwonmac/issues/new?template=bug-report.yml) zu öffnen, oder **Help → Request a Feature…** für das [Feature-Formular](https://github.com/gwonmac/gwonmac/issues/new?template=feature-request.yml).
2. Diagnosedaten sind optional; das Menü ist englisch. Unter **Help → Diagnostics → Export Recent Diagnostics…** kannst du eine bereinigte ZIP-Datei zum Anhängen erstellen. Zugangsdaten, Kontokennungen und Paketinhalte sind nie enthalten.
3. Bei Rucklern wählst du **Help → Diagnostics → Start Performance Capture**, reproduzierst das Problem, drückst <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> und beendest danach die Aufzeichnung.
4. Für schnelle Fragen ist der [Discord](https://discord.gg/Z9ft52RBD3) der kürzeste Weg.
