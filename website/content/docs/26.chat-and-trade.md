These Features sit beside Guild Wars' own chat. Each one has its own page:

- [Whispers]($docs.whispers): a movable panel for whisper conversations.
- [Trade Chat]($docs.trade-chat): browse Kamadan and Pre-Searing trade offers and trader prices.
- [Chat Filters]($docs.chat-filters): hide selected system notices.
- [Call Target]($docs.call-target): call the selected target from a key you choose.

Turn each one on in the launcher's Features page. They are off while you play the :setting[plain game]{to="tools/gwonmacTools"}. The two parts below belong to the Hub and the game.

## Invite to party

In an outpost, type `invite` and the full character name in the Hub to invite that character. Only an exact name invites; a part of a name opens that person's actions instead. Type `invite ` with a space to list your online friends. Guild Wars answers in chat.

For a friend who is in another PvE outpost, **Travel and invite** travels there, then sends the invite once you arrive. If you change character first, or the trip does not arrive, no invite is sent.

- **Turn on:** :setting[Whispers]{to="tools/tool:whispers"} or :setting[Travel]{to="tools/tool:quick-travel"}. **Travel and invite** needs Travel.
- **Open:** <kbd>⌘</kbd> <kbd>R</kbd>, then `invite` and a name, or choose **Invite to party** on a person.
- **Limits:** PvE outposts only. **Travel and invite** is not offered for PvP outposts such as Random Arenas. If you land in a different district from your friend, Guild Wars cannot find them.

## Pasted text

A name copied from Discord or a web page can carry a trailing space or an invisible character, and the game then cannot find that player. When you paste into a game text field, GWonMac removes those first, so the name works like a typed one. Password and email fields are never changed.

- **Turn off:** :setting[Clean pasted text]{to="game/pasteCleanup"} in Settings → Game. It is on by default. With it off, text is pasted exactly as it was copied.
