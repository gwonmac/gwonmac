Guild Wars speichert jeden Build als kurzen Template-Code. Unter Windows sind das `.txt`-Dateien in `Dokumente\Guild Wars\Templates`, die du zwischen Rechnern kopieren kannst. Auf dem Mac liegen sie im Speicher des Spiels selbst, an den der Finder nicht herankommt — deshalb gibt es die **Build Library** von GWonMac als Weg hinein und hinaus.

## Die Build Library einschalten

Die Build Library ist ein Feature. Schalte auf der Seite **Features** im Launcher :setting[Play the plain game]{to="features/gwonmacTools"} aus und dann :setting[Build Library]{to="features/tool:build-management"} ein. In einem Spielfenster öffnest du sie mit <kbd>⌘</kbd> <kbd>B</kbd> oder über **View → Build Library** (die Menüs der App sind englisch).

## Einen geteilten Code importieren

Du hast einen Code von einer Gilden-Seite, aus dem Wiki oder aus einem Chat kopiert? Wähle in der Build Library **Import build**, füge den Code ein und gib dem Build einen Namen.

## Template-Dateien importieren und exportieren

Wenn du vorher unter Windows gespielt hast — auf einem PC, in Parallels oder VMware oder über CrossOver —, liegen deine Builds bereits als `.txt`-Dateien vor. Kopiere den Ordner `Guild Wars` (oder nur dessen `Templates`-Ordner) auf deinen Mac. Öffne dann in der Build Library den Tab **Builds** und wähle **Template files**.

- **Import:** Wähle **Folder…** für einen ganzen Templates-Ordner oder **Files…** für einzelne `.txt`-Dateien. GWonMac zeigt, wie viele Templates es hinzufügt und was es überspringt. Wähle bei bereits vergebenen Namen **Keep existing** oder **Replace** und dann **Import**. Skill- und Ausrüstungs-Templates funktionieren beide. Ein Windows-Unterordner bleibt als Teil des Template-Namens erhalten, weil Guild Wars auf dem Mac keine Unterordner auflistet: Aus `Warrior\Shockaxe` wird `Warrior - Shockaxe`.
- **Export:** **Export all…** speichert jedes Skill- und Ausrüstungs-Template als `.txt`-Datei in einem Ordner deiner Wahl. Wiederherstellen heißt, diesen Ordner wieder zu importieren.

Importierte Templates landen in der eigenen Template-Liste des Spiels, nicht in der Build Library. Öffne im Spiel das Template-Fenster und wähle **Refresh List**, damit sie erscheinen — Guild Wars liest die Liste einmal pro Sitzung. Guild Wars listet höchstens 550 Templates je Art auf.

::note{icon="lucide:info"}
Dass Unterordner nicht gelesen werden und die Grenze bei 550 liegt, ist eine Einschränkung in ArenaNets Client, nicht in GWonMac. Sie ist zusammen mit den anderen gemeldeten Client-Fehlern dokumentiert — siehe [Anfragen an ArenaNet]($docs.upstream-requests) (englisch).
::

## Einen Build im Spiel verwenden

Öffne einen Build und wähle **Save to Guild Wars**. Der Build wird in die Template-Liste des Spiels geschrieben. Öffne danach das Template-Fenster im Spiel und wähle **Refresh List**, oder starte das Spiel neu.

Direkt nach einem Guild-Wars-Update kann **Save to Guild Wars** kurz nicht verfügbar sein, während GWonMac den neuen Client prüft. Der Build bleibt in deiner Library gespeichert.

## Einen Build teilen

Öffne einen Build und wähle **Copy code**. Den Code kann jeder in Guild Wars oder ein anderes Build-Werkzeug einfügen.
