Compass ranges draws rings for Shout, Cast, Spirit and Ext. Spirit range around you on the Compass, so you can see who a skill will reach before you use it.

### Details
- **Turn on:** :setting[Compass ranges]{to="features/tool:compass-ranges"}, off while you play the :setting[plain game]{to="features/gwonmacTools"}. It is off by default.
- **Open:** the round control beside the Compass shows or hides the rings and has options for them. In the [Hub]($docs.hub), the **Compass ranges** row opens these settings.
- **Settings:** each ring can be turned off and has its own opacity. :setting[Range colors]{to="features/compassRangeTheme"} sets Color or Monochrome.
- **Limits:** supported PvE maps only.
