Target Distance shows how far away your selected target is.

### Use it
1. Turn it on.
2. Select a target.

Drag the readout in a game window at any time to move it. It keeps its distance from the nearest corner. Under its **Options**, :setting[Reset position]{to="tools/targetReadoutPosition"} returns it to the top centre.

### Details
- **Turn on:** :setting[Target Distance]{to="tools/tool:target-readout"}, off while you play the :setting[plain game]{to="tools/gwonmacTools"}.
- **Open:** always visible once on. It has no window or shortcut.

> It works in PvE only.
