Switch Character shows your characters as cards. Choose one, and the game signs in to it without a logout. It also works from the character selection screen.

### Use it
1. Press <kbd>⌘</kbd> <kbd>E</kbd>, or search **char** in the Hub.
2. Type a name or a primary profession.
3. Press Enter, or double-click a card.

Each card can show the profession, the level and where the character is. Turn each one on or off in the settings.

> In an explorable area it asks before it leaves. While a map loads or in active PvP, it does not switch.
