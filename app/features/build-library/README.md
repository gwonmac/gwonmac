The Build Library keeps your skill builds and hero teams in one place, so you can load them in the game.

### Use it
1. Press <kbd>⌘</kbd> <kbd>B</kbd>.
2. Choose **Import build** and paste a template code, or open a build you saved.
3. Choose **Save to Guild Wars** to add it to the game’s template list.

**Copy code** gives a code that anyone can paste into Guild Wars. **Template files** imports and exports the template files Guild Wars uses on Windows.

> Guild Wars reads its template list once per session. Choose **Refresh List** in the game’s template panel to see a new build.
