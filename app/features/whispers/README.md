Whispers is a movable panel for whisper conversations, one conversation per person. Guild Wars’ own chat keeps working as before, and a reply you type there shows in the panel too.

### Use it
1. Press <kbd>⌘</kbd> <kbd>D</kbd>, or type **whisper** and a name in the Hub.
2. Pick a person from friends, open conversations, recent people or names seen in chat.
3. Type your message and press Enter.

A small icon shows unread messages. You can hide it; the shortcut and the Hub still open Whispers.

> Conversations last for this session only. They clear when you leave the game, change character or turn Whispers off.
