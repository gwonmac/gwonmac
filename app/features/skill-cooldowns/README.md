Skill Cooldowns puts a number on each recharging skill in your skill bar. It shows whole seconds, and tenths in the last 3 seconds. A ready skill shows no number.

### Use it
Turn it on. The numbers show at once.

Pick one :setting[Timer color]{to="tools/skillCooldownColor"} for all eight timers: red, cream, gold, blue, or **Custom**.

### Details
- **Turn on:** :setting[Skill Cooldowns]{to="tools/tool:skill-cooldowns"}, off while you play the :setting[plain game]{to="tools/gwonmacTools"}.
- **Open:** always visible once on. It has no window or shortcut.

> It works in PvE only.
