Trade Chat is a window to browse recent trade messages from Kamadan and Pre-Searing. It only reads; you post your own offers in Guild Wars, as before.

### Use it
1. Press <kbd>⌘</kbd> <kbd>K</kbd>, or type **trade** and an item in the Hub.
2. Search for an item or a character name.
3. Select an offer to read it, copy it, or whisper the seller.

**Saved** keeps the offers you starred and the players you follow. **Trader prices** shows Kamadan trader quotes with a short history.

> Trade Chat needs an internet connection. It reads a public trade feed from kamadan.gwtoolbox.com and ascalon.gwtoolbox.com.
