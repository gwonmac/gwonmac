The Elite Skill Planner helps you capture elite skills. It lists every elite skill with its boss, where to find the boss, and whether this character has learned the skill.

### Use it
1. Open the World Map and select the control in its upper-right corner.
2. Star a skill to add it to your **Hunt list**.
3. Follow the boss marker on the Mission Map to your **target**.

The next boss on the Hunt list becomes your target automatically: this area first, then this region. Use **Set target** to pick another, and **Use automatic target** to go back. A captured skill stays on the list with a tick. **Remove captured from Hunt list** clears them. The Hunt list is kept for each character.

The planner switches between **All matches** and **Hunt list**. Filters apply to All matches: search, class buttons (**Mine** follows your professions), **Not learned**, **Learned** or **Any**, and region. On the Mission Map, boss markers show where the boss can spawn. Click a marker to set it as your target, add it to your Hunt list, or open the planner. From the [Build Library]($docs.build-library)’s skill view, **Find capture locations** opens the same details.

### Details
- **Turn on:** :setting[Elite Skill Planner]{to="features/tool:elite-skills"}, off while you play the :setting[plain game]{to="features/gwonmacTools"}. It is on by default.
- **Open:** the control in the World Map’s upper-right corner. In the [Hub]($docs.hub), the **Elite Skill Planner** row opens these settings.
- **Settings:** :setting[Mission Map markers]{to="features/eliteMissionMapMarkers"} shows boss markers for the **Hunt list**, **All planner matches** or **Off**.
- **Limits:** supported PvE maps only. A skill counts as learned only when the game reports it for the current character. Boss positions are spawn points, not live positions.
