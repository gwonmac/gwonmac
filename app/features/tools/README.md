Features are the optional extras GWonMac adds to Guild Wars. This switch loads them when the game starts.

### Play the plain game
1. Open Settings › Tools.
2. Turn on **Play the plain game**.
3. Start the game again.

The plain game loads no Feature. Your choice for each Feature stays saved, so turning the plain game off again gives you back every Feature as it was.

> The Hub stays available in the plain game.
