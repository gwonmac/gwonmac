Xunlai Storage opens your storage window without a walk to the chest. It is the normal Guild Wars storage window, so you use it as usual.

### Use it
1. Stand in a supported outpost.
2. Press <kbd>⌘</kbd> <kbd>S</kbd>, or search `storage` in the [Hub]($docs.hub).

With storage open, [Quick Item Move]($docs.quick-item-move) moves whole stacks with one click.

### Details
- **Turn on:** :setting[Xunlai Storage]{to="features/tool:xunlai-storage"}, off while you play the :setting[plain game]{to="features/gwonmacTools"}. It is off by default.
- **Open:** <kbd>⌘</kbd> <kbd>S</kbd>, **View → Open Xunlai Storage**, the chat command `/chest` or `/xunlai`, or search `storage` in the Hub. You can change the key on its Feature page.

> If your character cannot reach storage where you stand, nothing opens and no error appears.
