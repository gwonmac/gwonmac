Skill Key Labels draws your own key names on the eight skill slots. Use it when your Guild Wars controls are not 1 to 8.

### Use it
1. In :setting[Skill labels]{to="tools/skillKeyBindings"}, choose **Set label** for a slot.
2. Press the key you use for that slot, or click or scroll in the capture box. Modifier keys count; Escape cancels.
3. Repeat for the other slots.

It changes only what is drawn. It does not change any Guild Wars key. A slot you leave unset keeps its number. **Use default** clears a slot.

### Details
- **Turn on:** :setting[Skill Key Labels]{to="tools/tool:skill-key-labels"}, off while you play the :setting[plain game]{to="tools/gwonmacTools"}.
- **Open:** always visible once on. Set the labels in Settings → Tools.

> It works in PvE only.
