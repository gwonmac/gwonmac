Skill Key Labels draws your own key names on the eight skill slots. Use it when your Guild Wars controls are not 1 to 8.

### Use it
1. In the settings, choose **Set label** for a slot.
2. Press the key you use for that slot.
3. Repeat for the other slots.

It changes only what is drawn. It does not change any Guild Wars key. A slot you leave unset keeps its number.

> It works in PvE only.
