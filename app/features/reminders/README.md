Reminders print a line in your own chat, starting with `[gwonmac]`, a minute before a con, pcon or alcohol effect runs out, and again when it has. Only you see these lines. Nothing is sent to other players.

### Use it
1. Turn on Reminders.
2. Choose what to be reminded about: :setting[Cons]{to="features/reminderCons"}, :setting[Pcons]{to="features/reminderPcons"}, :setting[Alcohol]{to="features/reminderAlcohol"}.
3. Choose when: :setting[1 minute before it runs out]{to="features/reminderBeforeEnd"}, :setting[When it has run out]{to="features/reminderAtEnd"}, or both.

You can add :setting[Play a sound]{to="features/reminderSound"}: one short chime, even when several reminders arrive together. With no item or no time chosen, nothing appears.

### Details
- **Turn on:** :setting[Reminders]{to="features/tool:reminders"}, off while you play the :setting[plain game]{to="features/gwonmacTools"}. It is off by default.
- **Limits:** PvE only. Using a con again starts its reminders over. If the effect ends early, for example when you die, enter an outpost or change character, there is no “has run out” line.

> Con and pcon times are exact. Alcohol is an estimate, so its lines say “about”.
