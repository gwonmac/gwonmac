Reminders print a line in your own chat a minute before a con, pcon or alcohol effect runs out, and again when it has. Only you see these lines.

### Use it
1. Turn on Reminders.
2. Choose what to be reminded about: cons, pcons or alcohol.
3. Choose when: one minute before, when it has run out, or both.

You can add one short chime.

> Con and pcon times are exact. Alcohol is an estimate, so its lines say “about”.
